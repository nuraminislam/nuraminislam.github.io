# Nur Amin - Personal Portfolio

Welcome to the repository for my personal portfolio website. This is a dynamic, fully responsive, and highly customizable portfolio built to showcase my journey, work experiences, projects, and skills.

## 🚀 Features

- **Fully Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop devices.
- **Dark/Light Theme:** Integrated theme switching for an enhanced and accessible user experience.
- **Dynamic Configuration:** Easily configurable sections (Journey, Education, Work Experience, Projects, Skills, and Clients) via a single `portfolio.js` file.
- **Infinite Scrolling Marquee:** A smooth, uninterrupted, auto-scrolling showcase of featured clients.
- **Interactive UI:** Features smooth scrolling, Lottie animations, and modern, clean UI/UX aesthetics.

## 🛠️ Built With

- **[React.js](https://reactjs.org/)** - Frontend library for building the user interface.
- **Vanilla CSS** - For lightweight, custom styling and animations.
- **[FontAwesome](https://fontawesome.com/)** - For crisp, scalable vector icons.
- **[Lottie](https://lottiefiles.com/)** - For lightweight, interactive animations.

## 💻 Running Locally

To run this project on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nuraminislam/nuraminislam.github.io.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd "Github Portfolio"
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```
   *The application will automatically open in your default browser at `http://localhost:3000`.*

## ⚙️ Customization

All the text, skills, experiences, and project details are stored in a centralized configuration file. 
To update the portfolio with new information, simply navigate to `src/portfolio.js` and modify the respective JSON objects.

## 📦 Deployment

This project uses `gh-pages` for deployment. To deploy updates:

1. Ensure your changes are committed.
2. Run the deployment command:
   ```bash
   npm run deploy
   ```
